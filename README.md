# 🚀 CA Resume AI

An AI-powered resume analysis and enhancement platform that helps users create, optimize, and improve resumes for better job opportunities. The application leverages Artificial Intelligence to provide personalized suggestions, ATS-friendly recommendations, and resume insights.

---

## 📌 Features

- 🤖 AI-powered resume analysis
- 📄 Resume upload and parsing
- 📊 ATS (Applicant Tracking System) score evaluation
- ✨ Smart resume improvement suggestions
- 🎯 Skill gap identification
- 📝 Resume content enhancement
- 🔍 Keyword optimization for job descriptions
- 📱 Responsive and user-friendly interface
- 🔐 Secure user authentication

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/singhalunnati864-ux/ca-resume-ai.git
cd ca-resume-ai
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Configure Environment Variables

Create a `.env` file in the root directory and add:

```env
OPENAI_API_KEY=your_api_key
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```

### 4️⃣ Run the Development Server

```bash
npm run dev
```

The application will be available at:

```bash
http://localhost:3000
```

## 🎯 How It Works

1. Upload your resume.
2. AI analyzes the resume content.
3. ATS score is generated.
4. Improvement suggestions are provided.
5. Optimize your resume based on recommendations.
6. Download the improved version.
